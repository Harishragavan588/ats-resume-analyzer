# ATS Resume Analyzer

A **complete, local, real-time ATS (Applicant Tracking System) Resume Analyzer** built with Python/Flask, NLP, and machine learning. Upload your resume (PDF or DOCX), paste a job description, and get an instant, explainable match score — no API keys, no external services required.

> **Disclaimer:** Scores are estimated match indicators generated by this application. They are NOT official ATS scores and should not be used for hiring decisions.

---

## Features

| Feature | Details |
|---|---|
| Resume parsing | PDF (PyPDF2) and DOCX (python-docx) |
| Keyword matching | 200+ technical skills vocabulary + custom extraction |
| Text similarity | scikit-learn CountVectorizer + Cosine Similarity |
| ML classification | Multinomial Naive Bayes job category predictor |
| Weighted scoring | Keyword 40% · Similarity 30% · Experience 20% · Formatting 10% |
| Explainable feedback | Rule-based engine — no LLM required |
| Database | SQLite + SQLAlchemy ORM |
| Downloadable reports | PDF via reportlab |
| Before/After comparison | Compare two analyses of the same role |
| Analysis history | Paginated table of all past analyses |
| Premium UI | Glassmorphism, animated gauge, responsive design |

## Windows Setup (PowerShell)

### Step 1 — Navigate to the project

```powershell
cd C:\Users\Lenovo\.gemini\antigravity-ide\scratch\ats_resume_analyzer
```

### Step 2 — Create & activate virtual environment

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

> If you get an execution policy error, run:
> `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`

### Step 3 — Install dependencies

```powershell
pip install -r requirements.txt
```

### Step 4 — Configure environment (optional)

```powershell
Copy-Item .env.example .env
# Edit .env if needed (default settings work out of the box)
```

### Step 5 — Generate sample test files

```powershell
python sample_data/create_samples.py
```

### Step 6 — Run the application

```powershell
python app.py
```

Open your browser at: **http://127.0.0.1:5000**

## API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/` | Main analysis page |
| GET | `/history` | History + comparison page |
| GET | `/result/<id>` | Single analysis result page |
| GET | `/api/health` | Health check |
| POST | `/api/analyze` | Upload resume + JD, return analysis JSON |
| GET | `/api/history` | Paginated list of past analyses |
| GET | `/api/analysis/<id>` | Retrieve single analysis |
| POST | `/api/compare` | Before/after comparison |
| GET | `/api/report/<id>` | Download PDF report |

### POST /api/analyze

**Request:** `multipart/form-data`
- `resume`: PDF or DOCX file (max 5 MB)
- `job_description`: plain text string (min 30 chars)

**Response:**

  "success": true,

## ATS Scoring Weights (Configurable)

| Component | Default Weight | Source |
|---|---|---|
| Keyword match | 40% | Skill vocabulary matching |
| Text similarity | 30% | Cosine similarity (CountVectorizer) |
| Experience signals | 20% | Action verbs, resume length, matched keywords |
| Formatting checks | 10% | Section headers, contact info, structure |

Change weights in `.env`:
```
SCORE_WEIGHT_KEYWORD=40
SCORE_WEIGHT_SIMILARITY=30
SCORE_WEIGHT_EXPERIENCE=20
SCORE_WEIGHT_FORMATTING=10
```

## Troubleshooting

### PDF parsing returns empty text
- The PDF may be scanned/image-based. Use a text-layer PDF.
- Try saving the PDF from Word or Google Docs as PDF instead of printing-to-PDF.

### DOCX shows no text
- Ensure the DOCX is not corrupted and contains actual text paragraphs.
- Check that python-docx is installed: `pip show python-docx`

### `ModuleNotFoundError`
- Make sure your virtual environment is activated: `.\venv\Scripts\Activate.ps1`
- Reinstall: `pip install -r requirements.txt`

### `sqlite3.OperationalError: no such table`
- The database initialises automatically on `python app.py`.
- To manually reset: delete `ats_analyzer.db` and restart the app.

### Upload size error (413)
- Increase `MAX_UPLOAD_SIZE_MB` in `.env`

### `Set-ExecutionPolicy` error
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

## Security Notes

- All uploaded files are validated (extension + content-type)
- Files are deleted from disk immediately after parsing
- Filenames are sanitised with `werkzeug.utils.secure_filename`
- No resume text is written to logs
- Database queries use SQLAlchemy ORM (parameterised, no raw SQL injection)
- No hardcoded secrets — use `.env` for all configuration

---

## Classifier Limitations

The Multinomial Naive Bayes job-category classifier uses a small, hand-curated
training corpus and is intended for illustrative purposes only.

- Predictions may be inaccurate for short or ambiguous resumes.
- Only 7 broad categories are recognised.
- **Do not use this classifier for hiring or employment decisions.**
